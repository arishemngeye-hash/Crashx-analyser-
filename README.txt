# CrashX Analyzer — version bêta

Application web mobile de statistiques pour résultats CrashX saisis par l'utilisateur.

## Ouvrir
Ouvrir `index.html` dans un navigateur moderne. Les résultats sont enregistrés dans le stockage local du navigateur.

## Publier gratuitement avec GitHub Pages
1. Dans ton dépôt GitHub, ajoute `index.html` à la racine (Add file → Upload files).
2. Ouvre Settings → Pages.
3. Dans Build and deployment, sélectionne Deploy from a branch.
4. Branche `main`, dossier `/ (root)`, puis Save.
5. Attends le lien Pages et ouvre-le dans Safari. Safari → Partager → Ajouter à l'écran d'accueil.

## Limites importantes
- Ce prototype ne se connecte pas au compte 1xBet et ne collecte pas les données en direct.
- Ne saisis jamais tes identifiants, mots de passe, codes SMS ou données de paiement.
- Les statistiques historiques ne permettent pas de prédire le prochain crash ou garantir un gain.
- Pour une connexion automatique, il faudrait une API officielle et autorisée de 1xBet, disponible pour ce jeu. Ne contourne pas les protections ni les conditions du site.
